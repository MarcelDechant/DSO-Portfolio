# Cloud VM Server Setup & Hardening

## Overview

This project was the foundation of my DevSecOps training environment. The goal was to set up and secure a cloud-based Linux server that was later used to deploy and host further projects during the course.

The server was configured with secure SSH key authentication, password-based SSH access was disabled, and an Nginx web server was installed and customized for hosting web applications.

Additionally, SSH connection aliases were configured to simplify server administration and improve the workflow when managing the remote environment.

## Technologies

- Linux
- Ubuntu
- Cloud VM
- SSH
- SSH Keys
- Nginx
- Bash
- Server Administration

## Implemented Features

- Initial setup and configuration of a cloud server
- Secure SSH access using key-based authentication
- Disabled password-based SSH login for improved security
- Installed and configured Nginx web server
- Created custom web server configuration
- Prepared the server environment for future deployments
- Configured SSH aliases for easier server management

## What I Learned

Through this project, I gained practical experience in Linux server administration, secure remote access, and basic server hardening.

This setup created the foundation for deploying and managing further projects during my DevSecOps training.

## Conclusion

This project represents my first step into cloud infrastructure and server management. It provided the foundation for later topics such as containerization, deployment workflows and automation.
